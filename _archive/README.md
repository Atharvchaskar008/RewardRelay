# Archive

This folder contains files that are not actively used in the production site but are kept for reference.

## Contents

### `/prototypes/`
- **ALEXANDER_ASCIII.html** - Early prototype of hero section with dotted rider artwork

### `/reference/`
- **AINO_ASCII_NAVBAR.txt** - ASCII art reference for navbar
- **ARCHE_INSPO.txt** - Inspiration notes from ARCHE design
- **ASCII_flame.txt** - ASCII flame character reference
- **PLUSH_MST_TILE.txt** - MST tile design reference

### `/ascii-eye/`
Original React/TSX implementations:
- **AsciiEye.tsx** - Original React component
- **AsciiEye_MST.tsx** - MST-branded version with logo
- **README_ASCII_eye.md** - Integration documentation
- **README_MST.md** - MST-specific docs

### `/eyeTutorial-main/`
Python-based eye animation tutorial (external reference):
- **eye.py** - Python implementation
- **Glossary.txt** - Terms and concepts
- **README.md** - Tutorial documentation
- **.gitattributes** - Git configuration

## Why Archived?

These files were moved here because:
1. They are prototypes or earlier versions superseded by current implementations
2. They are reference materials not directly used by the site
3. They are in different tech stacks (React/Python) vs current vanilla JS implementation

## Recovery

If you need to restore any file, simply move it back to the root or appropriate folder. All files are preserved with their original content.
